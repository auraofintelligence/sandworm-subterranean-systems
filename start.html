Why Dig?

Start with the reasons: fewer animal deaths, safer movement, erosion control, useful spoil, reef habitat, power storage and community assets.

Reasons before scale

The question is not "can we dig?" The question is "what would digging need to heal?"

Sandworm becomes worth exploring only if each layer solves something people already care about.

  1. Begin at a civic lab

    Use Dunwich / Gumpi as a maker-space and open-data start because the transport system is already visible there.

  2. Map animal movement

    Ask where underpasses, culverts or service tunnels could reduce road deaths without making new harms.

  3. Track the spoil

    Every bucket of sand needs a source, test, destination, risk check and possible useful second life.

  4. Prototype coastal help

    Artificial reefs, dune stabilisation, oyster-crete and seagrass lattices belong behind ecology and cultural review.

  5. Store power in sand

    Clean power only matters if it becomes reliable, quiet and useful through storage and local benefit.

  6. Tell the truth well

    Film and documentary can invite support while showing doubts, unknowns and reviewer voices.
