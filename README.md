# Sandworm Subterranean Systems | First-principles edition

New independent site prepared for Cloudflare, preserving the original GitHub Pages edition on main. Research snapshot 26 November 2026.

14 substantive chapters, licence, cost and material scenario calculators, original SVG diagrams and favicon, responsive navigation, footer chapter links, previous/next and return to top. No accounts, backend, telemetry or dependencies. This is not an approved engineering design.

## Deploy

Cloudflare Workers static assets: connect this repository and select branch `cloudflare-first-principles`, use the included wrangler.jsonc, no build step, deploy command `npx wrangler deploy`. Alternatively Cloudflare Pages: select this branch, no framework or build command, output directory `public`. Do not change the original GitHub Pages source branch.
