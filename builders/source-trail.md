## Boundaries

A source trail is not a truth badge. It helps people see what is known, what is imagined and what needs checking.

## Ways to use this Markdown with AI

Before sharing: inspect the file, remove private details, keep sources visible and decide whether the output is support, critique, learning or review.

### Support letter

Prompt: Using this Markdown as context, draft a respectful support letter in plain Australian English. Keep claims source-aware and list facts that still need checking.

### Expression of interest

Prompt: Using this Markdown as context, draft a short expression of interest from a community member, maker, funder, researcher or reviewer. Include possible next steps and boundaries.

### Reasons to slow or stop

Prompt: Using this Markdown as context, write a well-structured reasons-against note explaining which parts of the plan should not go ahead, should slow down, or need stronger evidence first.

### Lesson or workshop direction

### Evidence and risk check
